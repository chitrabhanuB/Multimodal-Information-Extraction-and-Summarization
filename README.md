# Multimodal Information Extraction and Summarization

## Overview

A pipeline for extracting information from POSTERSUM research posters and generating image-grounded academic summaries. Qwen2.5-VL inference is intended for Google Colab, preferably with a GPU runtime.

## Objectives

- Extract poster text with Tesseract and retain spatial OCR information.
- Filter words using a confidence threshold of 60 or higher.
- Generate an approximately 120–180 word summary grounded primarily in the poster image.
- Compare generated summaries with POSTERSUM abstracts using ROUGE-1, ROUGE-2, and ROUGE-L.

## Dataset

The pipeline loads `rohitsaxena/PosterSum` from Hugging Face Datasets. By default it uses the `test` split and reads each sample's `image_url`, `title`, and `abstract` fields. The abstract is the reference for ROUGE evaluation.

## Methodology

1. Download a poster image from the selected dataset sample.
2. Run English Tesseract OCR and retain confidence scores, word bounding boxes, and line identifiers.
3. Keep nonempty words with confidence `>= 60`, then group the words into spatial OCR lines.
4. Provide the poster image to Qwen2.5-VL-3B-Instruct as the primary source, with spatially grouped OCR text as supporting textual context.
5. Calculate ROUGE F1 scores against the sample abstract.

## Technology Stack

Python, Hugging Face Datasets, Tesseract OCR, pytesseract, Pillow, PyTorch, Transformers, Qwen2.5-VL-3B-Instruct, and `rouge-score`.

## Evaluation

`src/final_pipeline.py` calculates ROUGE-1, ROUGE-2, and ROUGE-L F1 scores using `rouge-score`. Results depend on the selected dataset sample and generated summary.

## Results

Evaluation used 3 POSTERSUM test posters. The average ROUGE F1 scores were 0.3862 for ROUGE-1, 0.1120 for ROUGE-2, and 0.1837 for ROUGE-L.

For Poster 2, OCR produced 462 words; 314 remained after confidence filtering, grouped into 22 spatial lines. The line-level visualization is `results/spatial_ocr_poster2_line_level.png`.

Poster 3 produced only 7 OCR words after processing, and its generated summary was incorrect. This illustrates the effect of OCR quality and difficult poster layouts on multimodal summarization.

## Limitations

- Tesseract can misread stylized text, equations, and dense poster layouts; confidence filtering may discard useful words.
- OCR line grouping does not fully represent poster sections or reading order.
- Qwen2.5-VL-3B-Instruct is resource-intensive; a Colab GPU runtime is recommended.
- ROUGE measures lexical overlap and does not by itself assess factual correctness or summary quality.

## Running in Colab

Open the notebook from the project root with a Colab runtime. Install the Python dependencies from `requirements.txt` and install the Tesseract system executable (`apt-get install tesseract-ocr`). Select a GPU runtime when available, then run the notebook cells in order. The notebook uses the second item in the POSTERSUM test split as poster 2.
